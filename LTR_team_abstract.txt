It is implemented a Neural Network (multilayer perceptron), trained with backpropagation on the provided dataset. The final selected model has the following architecture: 12 input units, 1 hidden layer with 24 hidden units (ELU activation function) and 3 output units(Linear activation). An hold-out technique is used to split the dataset in Selection Set (80%) and an internal Test set (20%).The model selection phase consists in a grid-searh with a k-fold(k =4) cross validition on the Selection Set. After model selection a retraining is performed on the entire selection set and the model performances are estimated on the  internal test set (risk assessment). Finally, to compute the prediction on the blind test set, the final selected model is retrained on the entire dataset (Selection Set + internal Test Set)
